# Pactile Code of Conduct / 行为准则

## Our standard / 我们的标准

We welcome contributors who are respectful, precise, and willing to preserve
evidence and ownership boundaries. Harassment, threats, discrimination,
deliberate credential exposure, and bad-faith tampering with project or user
data are not acceptable.

我们欢迎尊重他人、表达准确，并愿意维护 Evidence 与 ownership 边界的贡献者。骚扰、威胁、歧视、故意暴露凭据，以及恶意篡改项目或用户数据都不可接受。

## Enforcement / 执行

Report conduct concerns privately through the repository security channel or a
maintainer. Do not include secrets or private user data. Maintainers may remove
content, limit participation, or request a private clarification while keeping
the process proportionate and documented.

如需报告行为问题，请通过仓库安全渠道或维护者私下联系，不要附带 secret 或用户私有数据。维护者可以移除内容、限制参与或要求私下澄清，并保持适度且有记录的处理过程。
