# Cursor native modes — bind when native, degrade honestly

> **Purpose**: Cursor Adapter is **platform-only**. Bind Plan / Ask / Debug / Agent / Multitask when those surfaces are callable. Prefer native; **quietly** fall back to existing task artifacts when they are not. Do **not** reimplement modes. Do **not** publish a user-facing “this version doesn’t support mode X” list.
>
> **Human lifecycle** (Kernel projection): Open → Define → Approve → Execute → Verify → Integrate? → Close.
>
> **Not a Trellis Task**: official `/goal` / `CreateGoal`. Do **not** restore `cstl-goal`.

---

## Principle

| Layer | Duty |
| --- | --- |
| **Cursor native** | Plan / Ask / Debug / Agent / Multitask — bind when callable |
| **cstl artifacts** | `prd.md` / `design.md` / `implement.md` / `verify.md` / task `handoff.md` — quiet fallback when native cannot be driven well |

**Prefer native. Invent less.** Failures drop to those artifact paths with little commentary.

This guide is **on-demand**. It is not the always-on Bootstrap (`.cursor/rules/cstl-bootstrap.mdc`).

## Human phases ↔ Cursor modes

| Human phase | Cursor binding | Quiet fallback |
| --- | --- | --- |
| **Open** | Stay in Agent (or Ask if the user is already there and the ask is read-only) | Dashboard + Intake exits; no product writes |
| **Define** | **Plan** — try `SwitchMode(plan)` when useful | Write `prd.md` (and Full surfaces) in Agent |
| **Approve** | Agent — request the Execute gate; `--check` is not approval | Same artifacts; do not start Execute |
| **Execute** | **Agent** — `SwitchMode(agent)` when returning from Plan | Diff under the approved contract |
| **Verify** | **Debug** when runtime evidence is needed; else Agent | Proof always lands in `verify.md` |
| **Integrate?** | **Multitask** / Agent `Task` for Parent parallel workers | Explicit `.cstl/tasks/<dir>` prompts; Parent `integrate-child` |
| **Close** | Agent | `verify.md` coverage + `/cstl-finish-work` |

`Integrate?` is visible only when topology needs it (parent-child, or the task is already in Integrate). Lite single tasks skip it.

## Prefer / Adapt table (mode × lifecycle × artifacts)

| Cursor mode | Prefer when | Task-driven Prefer | Quiet cstl fallback | Durable artifacts |
| --- | --- | --- | --- | --- |
| **Ask** | Explain / lookup; **no** durable change | Prefer Ask UI / side chat when the user is already there. **Agent cannot `SwitchMode` → Ask** | In-session no-task read-only (no `task.py create` without consent) | None |

## Mode-specific contracts

### Ask ↔ no-task read-only

- Official Ask does not edit files.
- **Agent tools cannot `SwitchMode` into Ask.** If the user is not already on Ask, stay in Agent and keep the turn read-only.
- Pure Q&A is no-task; no task creation without consent.
- Side chats during Agent runs are still not Trellis artifacts.

### Plan ↔ Define

- Prefer **`SwitchMode(plan)`** for design-heavy **Define**; care about switch-back quality.
- Default plan save = **home directory** — **Save to workspace**, then map to `{TASK}/prd.md`, `design.md`, `implement.md` as the contract requires.
- Does **not** skip `start-execution --check` / Execute approval.
- If Plan switch or save flow is poor: **quietly** author the same files in Agent.

### Agent ↔ Execute

- Default binding for **Execute**.
- Stay inside the approved Definition / AC (and Full execution/verification contract).
- Contract change → Return-to-Define, then the Execute gate again.

### Debug ↔ evidence in `verify.md`

- Prefer Cursor Debug instrumentation when reachable.
- Always land proof in **`verify.md`**. Adapter does not ship Debug UI instructions.
- Contract change → Return-to-Define. Implementation defect → back to Execute.

### Multitask ↔ Parent parallel workers

1. Trellis remains source of truth for status, gates, integration. This is **not** a Trellis-built parallel product — Prefer Cursor Multitask / Build in Parallel / Agent `Task` / native worktree.
2. **Default parallel** when planning has ≥2 independent units (Parent children with empty `depends_on`, or Full Task fan-out). Lite / single-file work is not forced into parallel agents.
3. **Serial needs a written reason** (`serial_reason`): shared write-set / HITL or reviewer gate / `depends_on` unmet / user asked serial / conflict surface cannot isolate. HITL, `start-execution --approved`, reviewer gates, and `integrate-child` stay serial even when workers run in parallel (`merge_limit: 1`).
4. Every worker prompt includes **explicit `.cstl/tasks/<dir>`** — never rely on `selected_task`.
5. Parent alone `integrate-child`. See `.cstl/framework/parallel-first-execution.md`.

### Task API honest degrade (`generalPurpose`)

This Cursor Task API may have **no** `cstl-implement` / `cstl-check` enum.

- Dispatch workers as **`generalPurpose`**.
- Do **not** label the run `true-independent`.
- Do **not** nest further implement / check / research Task types from a child worker.
- Parent retains `review-child` / `integrate-child`.

---

## Official `/goal` is not a Trellis Task

- Cursor **`/goal`** / **CreateGoal** is a durable in-session objective on the Cursor product.
- It is **not** a Trellis task type, not Parent/Child, not `selected_task`.
- Do **not** restore `cstl-goal`. Continue / Finish-work / Handoff remain the `/cstl-*` escape hatches.

User-visible `/` escape hatches on agent-capable Cursor: **`/cstl-continue`**, **`/cstl-finish-work`**, **`/cstl-handoff`**. Internal skills (brainstorm, check, skill-creator, …) are **not** slash commands. `start` is filtered out on agent-capable Cursor.

## Callability (Agent tool table)

| Surface | Plan | Agent | Ask | Debug | Parallel children |
| --- | --- | --- | --- | --- | --- |
| Agent `SwitchMode` | Yes → `plan` | Yes → `agent` | **No** | — | — |
| Agent `Task` / Multitask | — | workers | — | — | Prefer **by default** (serial needs `serial_reason`) |
| User / CLI modes | Plan UI / `/plan` | default | Ask UI / `/ask` | Debug UI | `/multitask`, Build in Parallel |

If a cell is not callable here: **fail quietly** to the artifact paths above. Do not narrate an unsupported-mode catalog to the user.

---

## What cstl must not claim

- Plans auto-save into `.cstl/tasks/`.
- Multitask inherits `selected_task` or exposes a stable programmatic mode API.
- Parallel agents cannot conflict without Trellis/worktree discipline.
- `SwitchMode` can open Ask or Debug.
- Shipping a parallel fake Plan/Ask/Debug product, or documenting gaps as product blame.
- Replacing Cursor Multitask with a Trellis scheduler, queue, or new parallel CLI.
- That a `generalPurpose` stand-in is `true-independent`.
- That `/goal` / CreateGoal is a Trellis Task.

| Mode | Minimum probe | Pass when |
| --- | --- | --- |
| **Plan** | Schema or live `SwitchMode(plan)` note in verify | Prefer path documented; quiet Agent fallback if unused |

| **Multitask** | Task parallel or doc contract | Explicit child paths; default parallel; serial has `serial_reason`; Parent integrates |
| **Agent** | Session implements under contract | Artifacts on disk |
| **Task enum** | Missing `cstl-implement` / `cstl-check` | `generalPurpose` degrade; never `true-independent` |
