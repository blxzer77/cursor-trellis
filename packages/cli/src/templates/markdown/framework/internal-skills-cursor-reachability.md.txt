# Internal Skills Cursor Reachability Matrix

> **Purpose**: Every internal skill referenced by framework or task artifacts must have a documented **load channel** on a pure Cursor project. Root `AGENTS.md` is now a compact pointer block, not an invocation map. Internal workflow skills are **not** shipped to `.cursor/skills/` and have **no** default slash command — by design (commands-only). This matrix is the honest index: how each internal name is actually reachable on-demand, so an agent never claims a skill is loaded without a file read, and users never assume internal skills are slash commands.

## Commands-only baseline

- Default Cursor install writes only: `.cursor/commands/` (user slash commands), `.cursor/rules/*.mdc`, `.cursor/agents/*.md`, `.cursor/hooks`, and `.cstl/` (workflow, framework docs, scripts, spec/guides seeds).
- Bundled skill **bodies** live in the npm package templates (`dist/templates/common/skills/`, `dist/templates/common/bundled-skills/`). They are **not** copied into a consumer project by `cstl init` on Cursor.
- "Not in the project" ≠ "missing from the framework": the CLI/script/agent/guide surface below is the reachable carrier.

## Reading this matrix

- **Reachable on-demand** (green path): brainstorm → frontier guide; micro-grill → `intake-basic` before Task or the frontier guide after Open; check → agent; smart-search → script; **skill authoring → Read `cstl-skill-creator/SKILL.md` + `review-checklist.md`** (paths in the matrix row).
- **Body in npm package only**: the skill is real and shipped, but a pure Cursor project has no project-relative copy. Activated modules or task/interface artifacts route its **behavior**; the full body is discoverable under the installed package (`npm root -g` → `dist/templates/…`). Do not claim these are loaded without reading the actual body when the behavior matters.
- **Maintainer-only** (`cstl-meta`, `cstl-spec-bootstrap`): documented here for framework completeness; not part of the consumer execution path. No extra consumer load path beyond the package body.
- **Authoring-time mandatory** (`cstl-skill-creator`): not a consumer runtime path and not a slash command, but **must** be Read before creating or structurally changing Trellis / blaze-skills / harness skills. Cursor product skills are out of scope.

## Honesty rule

If a framework or task artifact names a skill, it must be reachable here. If a row ever becomes unreachable, add a project-relative carrier (guide/script/agent) or remove the stale reference. Root `AGENTS.md` remains a pointer block and need not enumerate internal skills. Never claim "skill loaded" without a file read.
