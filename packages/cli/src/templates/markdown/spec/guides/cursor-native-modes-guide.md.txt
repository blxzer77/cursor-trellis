# Cursor native modes — Prefer & orchestrate (don't replace)

> **Purpose**: Map Cursor **Plan / Ask / Debug / Agent / Multitask** to Trellis phases, Triage, and task artifacts. cstl **orchestrates and prefers** these surfaces; it does **not** reimplement them.
>
> **Product anchor**: `.cstl/workspace/cursor-trellis-product-positioning.md` (P1 — Prefer Cursor 适配).
>
> **External evidence (2026-08-05)**: `{TASK}/research/cursor-modes-external.md` + `research/smart-search/fetch-*.md`.
>
> **Rollback**: see [Rollback](#rollback) — delete listed files or restore from `cstl update` templates.

---

## Principle

| Layer | Owner |
| --- | --- |
| **Cursor mode UI** (Plan / Ask / Debug / Agent / Multitask) | Cursor — how this window works |
| **Trellis lifecycle** (Triage, phases, gates, artifacts, Parent/Child integration) | cstl — how work becomes durable engineering |

**Prefer native when it fits.** Fall back to cstl skills/commands (`cstl-brainstorm`, `cstl-break-loop`, Task subagents) when the native mode is unavailable (BYOK gaps, platform limits) or when Trellis gates require explicit CLI steps.

### Phase quick map

```
Triage (No Task / Micro-Grill)     → Ask (or side chat during Agent)
Phase 1 Plan                        → Plan (+ cstl-brainstorm); Save to workspace → task artifacts
Phase 2 Execute                     → Agent (+ worker Task subagents when contracted)
Phase 2–3 stuck / repeat failure    → Debug (+ cstl-break-loop)
Parent parallel children            → Multitask / Build in Parallel (post-approval)
```

## Mode-specific contracts

### Ask ↔ No Task boundary

- **Official Ask**: searches/reads; **does not edit files** (E1). Switch via **`Shift+Tab`** or mode picker; CLI `/ask` or `--mode=ask` (E2).
- **Trellis**: classify **No Task** for pure Q&A; **no** `task.py create` without consent.
- **Side chats (3.11)**: `/side` or `/btw` — read/search/answer **alongside** a running Agent thread; complements Ask; still **not** Trellis artifacts.
- **Upgrade**: durable change needed → consent → **Plan** (Phase 1) or **Agent** (post-approval).

### Plan ↔ Phase 1 artifacts

- Plan produces a **reviewable implementation plan** (chat + markdown); **Build** runs Agent implementation (E3).
- **Default save location is the user's home directory** — click **“Save to workspace”** before mapping into `{TASK}/prd.md`, `design.md`, `implement.md`.
- Plan does **not** skip `start-execution --check` / user execution approval.
- **`cstl-brainstorm`** remains for PRD grill — Plan complements it.

### Debug ↔ evidence

- Debug adds **instrumentation** → user reproduces → agent analyzes logs → **targeted fix** → removes instrumentation (E4).
- Trellis still requires **`verify.md`** proof; scope/contract change → Return-to-Planning.

### Multitask ↔ Parent/Child

1. **Trellis = source of truth** for status, gates, integration (E6–E7).
2. **Subagents = own context** — prompt must include task path, role, output files (E9); never rely on `selected_task`.
3. **Worktrees**: UI-native isolation in **Agents Window**; IDE uses `/worktree` skills (E8).
4. **No guaranteed collision prevention** on parallel `/multitask` (forum v0, E11) — worktrees + Parent review.
5. **Build in Parallel**: independent plan steps parallel; **dependent steps stay ordered** (E6).

See: `cursor-subagent-policy.md`, `execution-strategy.md`, `research/cursor-modes-external.md`.

## Switching modes (user vs Agent tool)

| Surface | Plan | Agent (builder) | Ask | Debug |
| --- | --- | --- | --- | --- |
| **User UI** | `Shift+Tab`, mode picker | same | same | same |
| **Cursor CLI** | `/plan`, `--mode=plan` | default | `/ask`, `--mode=ask` | (editor-focused in docs) |
| **Agent `SwitchMode` tool** | Yes → `plan` | Yes → `agent` | **No** — user UI | **No** — user UI |

When the Agent tool cannot switch, state the recommendation and continue via the closest cstl skill path.

## What cstl must not claim

See full table in `research/cursor-modes-external.md` § Q5. Short list:

- Plans auto-save into Trellis task directories.
- Multitask exposes a stable programmatic API or inherits `selected_task`.
- Parallel agents cannot conflict without Trellis/worktree discipline.
- `SwitchMode` replaces user Ask/Debug switching.
