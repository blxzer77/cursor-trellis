# 治理与社区

[English](index.md) | 简体中文

治理将当前说明、兼容承诺与历史事实分开。按角色选择页面：

| 角色             | 页面                             | 覆盖内容                              |
| ---------------- | -------------------------------- | ------------------------------------- |
| 贡献者           | [贡献](contributing.zh-CN.md)    | 环境、有限变更、测试与审查 Evidence。 |
| 安全研究者       | [安全](security.zh-CN.md)        | 私密报告、安全复现与披露。            |
| 维护者或集成人员 | [兼容性](compatibility.zh-CN.md) | 0.5.x window 与迁移边界。             |
| 发布负责人       | [发布](releasing.zh-CN.md)       | 候选检查、包顺序与发布控制。          |

社区入口是 [CONTRIBUTING.md](../../CONTRIBUTING.md)、[SECURITY.md](../../SECURITY.md) 与[支持](../../SUPPORT.md)。它们不会要求凭据或私有日志。[历史索引](../history/index.zh-CN.md)会把保留的实验、release note 与署名标为历史 Evidence。
